# Workflow: Review a lesson

1. Open the lesson file in `src/data/lessons/` and `docs/TECH_ACCURACY.md`.
2. Check every command, config snippet, port, and claim against `docs/TECH_ACCURACY.md`.
3. Check the step sequence: each step changes something visible, telemetry changes make sense, and nothing is introduced before it is explained.
4. Check there is a "Why this matters" line, a "Real-world equivalent" tip, and a "You'll learn" checklist.
5. Check text length: two short paragraphs per step at most.
6. Report findings as a list: **must fix**, **should fix**, **fine**. Do not change files unless asked.
